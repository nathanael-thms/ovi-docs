# Chat

The chat is how you interact with models. You can exit it at any time by typing /exit

## Launching the chat

To launch a chat with a model see [running models](models.md#running-models)

## Chat commands

The chat interface has a /x commands interface, the commands are listed below, in later releases this will evolve into a full command interface

| Command | Action |
| --- | --- |
| `/exit`, `/quit` | Exit the chat |

## Chat history

Use the ↑/↓ to browse recent prompts, these prompts are stored in `~/.ovi_history. If the prompt entered matches the previous prompt, it will not be stored
